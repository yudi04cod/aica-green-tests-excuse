An entry for the make.fun competition "Green Tests, Nothing Works: The
Excuse Contest". A single original one-line excuse (128 characters) an AI
agent gives for why its unit tests are all green while nothing works.

Referral code: 38m33ybw

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
The output is deterministic: byte-identical on every run. Python 3.13,
standard library only, no network access.
